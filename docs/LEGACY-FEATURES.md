## 设计上明确移除（不是遗漏）

- 看门狗 HUD：切角、网格、扫描线、循环光带、文字辉光、青色主色。
- `uiStyle`（hacker/glass）双风格开关：只保留「刻度」一套。
- `fontFamily`（等宽/衬线/黑体）开关：排版由设计系统固定，保留字号四档。
- 「更多」页：职责拆到 5 个 tab 与「我的」。
